# わけを はなそう

小学校受験の「1対1の口頭試問」（テスターと向き合い、口で答え、理由を話す形）を、年長の子が iPad で練習するアプリ。
ページ1枚（index.html）で動き、通信も外部の部品も使わない。問題は全部その場で作る（同じ形がまた出ることはある）。

## 2つの あそびかた

| あそびかた | だれが | もんだい文 | こたえ | そのあと |
|---|---|---|---|---|
| せんせいと | おとなが テスター役・子は立つ | おとなが 1回だけ読む（読んだら文は隠れる） | 子が指さし・声で。おとなが代わりにタップ | すぐ正解は出ず「どうして そう おもったの？」→ おとなが「はなせた／てつだって／もうすこし」を記録 → 正解・不正解 |
| ひとりで | 子が じぶんで | 画面に出る・読み上げあり | 子がタップ | 正解・不正解。1回目の間違いはヒント、2回目は解き方つきの答え |

「てつだって」＝言い方の型（「ほかのは みんな ○○ だけど、これだけ △△ だから です」など）を見せて真似させる。

## もんだいの かたち（11）

1つの かたちの 中に 解き方を いくつも 持つ（いちばん上は 全部を まぜる・同じ かたちが 2問 続くときは 解き方を かえる）。

| かたち | なに（解き方） | もとになった 型 |
|---|---|---|
| ひも | むすびめを ほどく・まがった ひも（ます目を数える）・はしが ずれた ひも・つないだ ぼう。いちばん上は 6本・3ばんめまで | 練習帳1（長さの推理） |
| くらべる | のんだ ジュースの りょう・まめの やま・おおきい じゅんに タップ・たいおう（多い順と大きい順を合わせる）・4ばんめ | 練習帳2・3（量の比較・系列・対応） |
| シーソー | 2〜3台から いちばん・2ばんめに おもい／かるい・つりあった台を含む・おきかえ | 練習帳4（推理） |
| かぞえる | いくつ ある（いちばん上は 2種を 1回で）・どちらが いくつ おおい・おなじ かずの はこ | 練習帳7・8・9（計数・差・同数） |
| わける | ひとり ○こずつで ぜんぶで いくつ（いちばん上は 2つの物を 1回で）・おなじ かずずつ わける・あまり | 練習帳10（分配） |
| かずの おはなし | ふえて へって・あげる もらう（2人の数）・くらべて いくつ おおい（聞いて答える） | 練習帳11（増減の文章題） |
| なかま | なかまはずれ＋わけ・ちかい はずれ（同じ いきもの の中）・にている ところ ちがう ところ・2つの なかまに わける（いちばん上は 12こ） | 練習帳5・6（分類＋理由） |
| おなじ え | ぜんぶ おなじ 1つ・1つだけ ちがう 絵・むきが ちがう おなじ 絵 | 練習帳12（細部の比較） |
| かたち | 2つ あわせて 形を作る・まわした かけら・きっても できない かけら・わける せん・ななめの きりかた・おりがみを きって ひらく | 練習帳13・14・16・17・20（構成・分割・回転・対称） |
| あなに ぴったり | こうしの あなに あう まるい ピース | 練習帳15（線の向きと位置） |
| おはなし | 絵で おはなしを つくる・しつもんに こたえる・どっちが すき（こたえの ない もんだい。せんせいと だけ） | 言語・口頭質問 |

- ふたつ きく＝いちばん上の ひも・くらべる・シーソー・かぞえる・わける は、1回の 読みで ○ と △ の 2つを 答える組が 出る。2つ目の前には △ の印だけ出す。違った印だけにヒント、2回目は その印の答え。片方だけ合っても組で まちがい1回
- まぜまぜ＝いろいろな型がつぎつぎ（本番の流れに近い）
- レベルは自動で上下＝1まわりの 8割を1回で正解すると上へ、4割以下なら下へ。いちばん上が本番の水準（`src/bench.js` の本番基準表で自己点検が照らす）
- 制限時間＝減っていく ぼう。秒数は練習帳の〈時間〉を1問あたりにならした値（ふたつ きく の組は〈時間〉そのまま）。じかんぎれは まちがい1回と同じ扱い（ばつなし）
- ごほうび＝みのり（正解で2・直せたら1・わけを はなせたら＋1）。たまご→ようちゅう→さなぎ→せいちゅう と育ち、24こで むしが1ぴき ずかんへ（ずかんは虫だけ＝3種の線画と甲虫44種）
- 「おとなのひと」を ながおし＝なまえ・1まわりの問題数・あそびかた・おと・よみあげ・記録・進め方・音のためし・ずかんの絵を全部見る

## 動く端末

2012年の iPad（iOS 10.3.3・Safari 10.1 相当）で動く書き方だけで書いてある。
新しい書き方・絵文字は使わない（`tools/check_es5.py`・`tools/check_chars.py` が止める）。

## つくりかた

- 直すのは `src/` の中だけ（`core.js`＝土台・音・記録・ごほうび／`bench.js`＝本番基準表／`gen.js`＝問題の型／`ui.js`＝画面／`template.html`＝入れもの）
- `python3 tools/build_app.py` が `index.html` と `offline.appcache` を組み立てる
- 直したら `src/core.js` の `APP_VERSION` と `version.txt` を同じ数字で +1 する
- `zsh tools/check_all.zsh` で検査（組み立て・古い書き方・字の在庫・漢字・書かない語・記録の名前・アイコン・自己点検＋既定の部品・横置き1画面・きめこまかい画面・制限時間）
- ホーム画面の絵は `python3 tools/make_icon.py` だけが作る
- 公開は `zsh push.zsh`（しげが実行）。組み立ての すぐ後に `check_all.zsh` を回し、FAIL なら送らずに止まる（試験＝`tools/test_push_neg.zsh`）
